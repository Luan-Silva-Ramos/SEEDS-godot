# Dark Fantasy Ambient VFX — Free 2 Overlay Sampler

Version: v1.0

## Included

- 2 complete transparent animated overlay effects
- 24 registered frames per effect
- 1280 x 720 RGBA PNG sequence masters
- 640 x 360 exact half-size RGBA PNG sequences
- 6 x 4 sprite sheet per effect at 640 x 360 per frame
- Compact animated GIF preview per effect
- Catalog CSV/JSON and animation metadata
- Browser demo, usage guide, license, disclosure, and SHA-256 manifest

## Animation contract

- Recommended playback: 12 fps
- Duration: 2.0 seconds
- Temporal loop: frame 23 returns to frame 0
- Fixed origin and canvas across all frames
- Spatial tileability is not claimed
- Compact GIF previews use 80 ms per frame (12.5 fps) because GIF timing is quantized; the transparent PNG sequence contract remains 12 fps

## Format statement

This is an engine-agnostic PNG-sequence and sprite-sheet product. It is not a shader, particle-system, video-alpha, Unity, Godot, Unreal, GameMaker, or RPG Maker package.

## Preview statement

Store previews may show dungeon backgrounds and labels. Those preview-only elements are not included unless listed in `CATALOG.csv`.
